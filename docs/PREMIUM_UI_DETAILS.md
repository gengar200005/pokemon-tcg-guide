브랜치: `ui/premium-card-studio`
범위: 스타일만 변경. main 미병합·미배포.

## 기존 UI와 적용 순서

index.html의 인라인 CSS 다음에 ui-theme.css가 로드된다. 인라인 CSS는 상태 표시(display/z-index), 기존 레이아웃, 컴포넌트 기본값을 제공한다. 테마 파일 안의 기존 관련 규칙을 교체하고, 기존에 테마 규칙이 없던 레시피/검증 결과에만 새 규칙을 추가했다. 홈/내비게이션/그리드/덱 구성 과정은 변경하지 않았다.

`!important`는 기존 4개 그대로이며 신규 사용은 0개다. 버튼의 비활성·키보드 포커스를 유지한다. 새로운 프레임워크·이미지·글꼴 요청은 추가하지 않았다.

## 전후 핵심 비교

| 대상 | 이전 | 개선 |
|---|---|---|
| 모달 공통 | 서로 다른 그림자/여백, 높이 기준 혼용 | 공유 표면/그림자/24px 반경 토큰, vh fallback + dvh·safe area 상한 |
| 일반 카드 모달 | 제목/내용의 구분이 약함 | 제목 하단 구분선, 내용 행의 일정한 여백, 긴 값 줄바꿈 |
| 닫기 버튼 | 표면마다 30~40px 기반 | 공통 44px 영역, 절제된 테두리와 눌림 배경 |
| 자동 구성 모달 | 헤더와 본문 경계가 약함 | 흰색 sticky 헤더, 설명 면 분리; 전체 모달 스크롤 유지 |
| 진화 선택 | 굵은 카드 테두리와 작은 보조 글씨 | 얇은 테두리, 충분한 행 간격과 보조 텍스트 |
| 덱 바텀시트 | 작은 썸네일/수량 버튼, 이름 한 줄 잘림 | 앨범형 행, 긴 이름 줄바꿈, 44px 조절 버튼과 숫자 정렬 |
| 레시피 카드 | 밝은 노랑 그라데이션·황색 버튼 | 아이보리 면·얇은 골드 프레임·차분한 보조 동작 |
| 검증 결과 | 작은 색상 텍스트 행 | 배경·테두리·기존 아이콘으로 구분된 읽기 쉬운 메시지 |
| 토스트 | 큰 그림자/둥근 알약 | 작은 라운드 패널, 일정한 그림자·줄바꿈·상단 안전 영역 |

화면 표시/숨김 클래스와 쌓임 순서는 변경하지 않았다. 자동 생성 모달은 필터·설명이 길어질 수 있어 내부 내용을 통째로 스크롤하도록 유지했다. 진화 선택은 목록, 덱 시트는 카드 목록을 스크롤하며 각각 min-height:0과 overscroll-behavior를 지정했다.

## 실제 렌더링 제한

기존 환경에서 브라우저 실행 파일이 없고 다운로드가 실패했던 상태다. 이번에는 설치를 반복하지 않았다. 실제 브라우저에서의 일반 모달/자동 생성/진화 선택/덱 시트/검증 모달/수량 변경/저장 덱 확인 및 전후 스크린샷은 **미실시**다.

360px·390px·430px과 태블릿·데스크톱은 미디어 규칙과 폭 계산을 소스에서 검토했으나, 해당 폭에서 실제 픽셀 배치가 검증된 것은 아니다. 안전 영역 padding과 dvh 상한, 입력 16px, 스크롤 보조를 적용했지만 iPhone 실기기의 키보드·회전·확대·고정 헤더 동작은 추가 확인이 필요하다.

## 남은 한계

일부 기존 토스트는 호출부의 인라인 배경색을 사용한다. 기능 코드 보존을 위해 이를 강제로 덮어쓰지 않았다. 레거시 인라인 CSS와 테마의 두 계층은 유지된다. 변경된 부분은 색상뿐 아니라 패널 내부의 여백·텍스트 줄바꿈·닫기/수량 조절 크기·스크롤 상한·피드백 면 구성이지만 전체 화면 구조는 의도적으로 그대로다.

실제 기기에서 긴 한글 카드명, 긴 검증 메시지, 모달 최대 내용, 작은 가로 화면, 키보드 열림 상태를 확인한 뒤 병합하는 것이 좋다. 사용자 승인 없이 병합·배포하지 않는다.
