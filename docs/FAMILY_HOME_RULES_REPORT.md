# 홈 연결 및 가족용 60장 놀이 방법

2026-11-02 · 작업 브랜치 `fix/deck-rules-simulation` · 미병합/미배포

## 기능 보존

새 홈과 데스크톱 사이드 메뉴를 기존 탭에 연결했다. 도감/내 카드/스캔/덱 보관함/놀이 방법은 기존 화면 ID를 그대로 사용한다. 홈에서 풀덱 만들기, 저장 덱 목록, 시판덱 구성표/등록에 직접 접근할 수 있다. 기존 하프덱·자유 모드, 수집함 등록/수량, 시판덱 일괄 등록, 저장 덱 열기/수정/삭제, 자동 구성 후보·시뮬레이션, Google 로그인·가족 연결은 제거하지 않았다.

미리보기의 가상 카드 목록이나 샘플 덱 데이터를 앱 데이터로 옮기지 않았다. 덱 생성 과정은 기존 실제 보유 카드 기반 UI/엔진을 재사용한다. 화면 시안의 단계별 생성기를 통째로 덮어씌우지 않았다. 스캔도 독립 메뉴로 유지한다. 저장 데이터 구조, Firebase 로직, 엔진, 카드 DB, 프리셋을 변경하지 않았다.

## 놀이 방법

`index.html`의 짧은 규칙 목록을 가족용 풀덱 안내로 교체했다. 아이용 핵심 문장과 부모용 펼침 설명으로 나누고 다음을 포함했다.

- 준비물, 덱/패/배틀필드/벤치/프라이즈/트래쉬의 자리와 시작 순서, 멀리건
- 60/7/6/5 핵심 숫자, 덱 구성과 특수 제한, 하프덱/자유 모드와의 구분
- 차례 시작 드로우, 첫 차례 선공/후공 차이, 자유 행동, 공격/차례 종료
- 일반 부착과 효과 부착, 기술 비용(타입/무색), 공격 후 에너지 유지
- 진화 시점·이름·계승 항목, 특성 사용 조건
- 아이템/서포트/도구/스타디움, 일반 후퇴와 효과 교체의 차이
- 카드에 적힌 약점/저항력, 누적 데미지, 기절과 새 배틀 포켓몬, 자기 프라이즈 획득
- ex/메가진화 ex 프라이즈 차이, 승패 조건, 덱 소진 시점
- 포켓몬 체크, 독/화상/잠듦/마비/혼란의 처리와 중복/회복
- 네스트볼/하이퍼볼/이상한사탕, 카드 명시 예외, 가족 연습과 정식 규칙의 구분

옛 고정 타입 상성표와 ‘동시 승리는 무조건 프라이즈1장 재대결’이라는 단순화는 삭제했다. 예외적인 동시 승패는 공식 판정 확인을 안내한다. 체크박스는 읽기 보조이며 게임 자동 판정이나 데이터 저장 기능이 아니다.
