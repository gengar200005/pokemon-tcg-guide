# 가족 카드 도우미 UI 정리

작업 브랜치: `fix/deck-rules-simulation`. 기존 PR #5는 이미 병합되어 있으므로 이번 변경은 해당 브랜치에만 추가하며 main에 병합하거나 배포하지 않는다.

## 변경

- 메인(도감): 흰색 헤더, 작은 캐릭터 탭, 읽기 쉬운 제목·보조 텍스트, 정돈된 카드 간격. 부모·아이 모두를 포함하는 헤더 문구.
- 덱 만들기: 틸 색의 명확한 주 CTA, 크림색 하프덱 버튼, 입력·필터·장수 블록의 통일된 형태. 수집함·저장 덱 카드도 동일한 테두리·여백 적용.
- 현재 덱 시트: 제목/카테고리/검증 메모/핵심 수량의 위계, 더 큰 수량 조절 버튼, 넓은 데스크톱 시트.
- 자동 구성·검증 모달: 밝고 차분한 헤더, 통일된 패널·메모·보조 버튼. 표시/숨김 클래스, z-index, 이벤트 연결은 유지.
- 스캔: 카메라 대비를 위한 어두운 화면 유지, 결과 패널은 차분한 녹색과 읽기 쉬운 보조 텍스트로 정리.
- 토스트, 포커스, 비활성 상태, 작은 화면 및 reduced-motion 대응.

## 파일과 스타일 시스템

`ui-theme.css`: 전용 표현 계층. 기존 인라인 CSS 뒤에서 로드되며, 기존의 레이아웃 및 상태 클래스는 그대로 사용한다. 색/글꼴/모서리/그림자/간격/포커스 토큰을 한 파일에 모았다. 주색 #216b59, 배경 #f6f8f7, 따뜻한 크림색 보조색. 장식 글꼴 Jua 대신 Noto Sans KR의 굵기로 제목 위계를 표현한다.

`index.html`: 테마 CSS 연결, 글꼴 요청 정리, 헤더 보조 문구만 변경. 기존 84개 id와 50개 클릭/변경/입력 핸들러가 원격 브랜치 버전과 동일함을 대조했다.

## 실제 검증

- `node --test tests/*.test.js`: **87 pass / 0 fail**. 기존 엔진/자동 구성/수동 편집/검증/저장 VM 회귀 유지.
- `node --check app.js`, `node --check deck-engine.js`, `git diff --check`: 통과.
- 테마 CSS의 중괄호·괄호 균형 검사 통과. 전용 CSS 파서가 없어 파서 기반 검사는 하지 못했다.
- 주요 텍스트 대비 계산: 주색/흰색 6.34:1, 보조색 #63766e/흰색 4.83:1, 본문 #52675f/배경 5.68:1. 모든 기존 인라인 색상 조합을 검사한 것은 아니다.
- 브라우저 실행 환경 부재 및 앞선 Chromium 다운로드 실패로 실제 화면 렌더링·스크린샷·터치 흐름은 미검증. 재설치 시도는 반복하지 않았다. Node 테스트 통과를 브라우저 시각 검증으로 표현하지 않는다.

## 영향과 한계

app.js, deck-engine.js, 카드 DB, 프리셋, 로그인·저장 구조는 이번 작업에서 수정하지 않는다. 스타일과 문구 변경만 포함한다. 레거시 인라인 색상과 일부 작은 배지는 남아 있으며 테마는 기존 CSS를 교체하는 전체 리팩터링이 아니라 추가 표현 계층이다. 후속 확인은 실제 모바일/데스크톱에서 자동 구성 → 수동 편집 → 검증 → 저장 → 재개방 및 긴 카드명/빈 수집함/가로 화면을 점검해야 한다. 디자인은 구현되었으나 시각 QA가 남아 있어 검토 후 병합할 수 있도록 브랜치에만 보관한다.
